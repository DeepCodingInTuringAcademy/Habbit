# 哈比兔
🐰 一个桌面端时间管理小助手 🍋🌿

![哈比兔Logo](assets/images/logo.png)

## 项目简介

哈比兔是一款集习惯养成、事项管理、番茄工作法和时间线记录于一体的时间管理软件。通过可爱的兔子主题和科学的时间管理方法，帮助用户提高工作效率，培养良好习惯。

## 主要功能

### 核心功能 ✅
- **习惯管理**
    - 创建/修改/删除习惯
    - 每日习惯打卡
    - 习惯进度追踪
- **事项管理**
    - 创建待办事项
    - 事项提醒(邮箱/系统日历)
    - 事项完成状态跟踪
- **时间线视图**
    - 每日活动时间线
    - 习惯打卡记录
    - 已完成事项展示
- **番茄工作法**
    - 可定制番茄钟时长
    - 计时结束提醒
    - 番茄记录备注
- **数据统计**
    - 习惯完成率饼图
    - 自定义时间段统计

### 特色功能 ✨
- 可爱的哈比兔主题皮肤
- 专注模式与禅定模式
- 多平台支持(Windows/Android/Linux)
- 数据云同步功能

## 技术栈

- **前端**: Qt框架(C++)
- **后端**: C++17 标准
- **数据存储**: Qt::Sql 数据库
- **构建工具**: CMake
